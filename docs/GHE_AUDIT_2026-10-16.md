| Constat | Cause | Correction source |
| --- | --- | --- |

## Limites explicites

L’audit navigateur couvre les parcours cités, pas toutes les pages administratives ni tous les rôles. La session de contrôle est celle de l’utilisateur connecté, pas une simulation des autres agents. Le viewport de contrôle est un navigateur de bureau ; la vérification Android reste nécessaire. Aucun message, invitation, e-mail, décision d’accès ou dossier professionnel n’a été soumis pour tester.

Le choix de collègues dans le formulaire loisirs conserve une liste locale de cases plutôt que le sélecteur commun : divergence structurelle constatée, à traiter avec les contraintes d’invitations de comptes non activés. Les anciens tests rouges restent un chantier identifié, pas une validation générale du site.

La lecture du changelog Supabase par réseau direct a été bloquée par le proxy de cet environnement ; la documentation officielle des tests Edge a été consultée via le connecteur. Aucun changement d’API, de dépendance, de schéma ou d’authentification serveur n’est introduit.
